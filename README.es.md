# ACP Enhanced

Addon Control Panel para World of Warcraft 3.3.5a (WotLK): un gestor de addons dentro del juego, con sets de addons. Se abre desde el botón **AddOns** del menú del juego o con `/acp`.

Basado en **ACP** de **sylvanaar, Rophy y Saien** (WotLK Community Edition mantenida por Mapache-Warmane2077), con licencia MIT. Todo el crédito del addon original es de sus autores.

## Qué cambia en esta versión

- **Sets por zona.** En el menú de sets, cada set se puede marcar como *Usar en campos de batalla*, *Usar en arenas* o *Usar en el resto*. Al entrar a una zona cuyo set no está cargado, sale una ventana que ofrece cambiar a ese set y recargar. Si ya está el set correcto, no hace nada.
- **Menos memoria.** Solo queda en memoria el idioma que usás; las demás traducciones se sueltan después de cargar.
- **Lista más fluida.** La memoria de los addons se actualiza como mucho cada 5 segundos, en vez de en cada paso del scroll y en cada click.

## Instalación

1. Descargá este repositorio (**Code → Download ZIP**).
2. Copiá la carpeta `ACP` en `World of Warcraft/Interface/AddOns/`.
